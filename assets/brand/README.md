# PowerLink brand assets (v1.0.0 review)

The interlocking white/cyan/blue links represent two playback endpoints, joined by a single cyan energy-transfer bolt.

- `powerlink-mark.svg`: primary dark-surface glyph, transparent background.
- `powerlink-mark-light.svg`: dark left link for light surfaces.
- `powerlink-mark-monochrome.svg`: one-color fallback.
- `powerlink-banner.svg`: repository and documentation masthead.
- `custom_components/powerlink/brand/icon.png` and `dark_icon.png`: Home Assistant custom integration visuals (PNG required).

No Home Assistant-owned artwork or branding is included. PowerLink is an independent Home Assistant custom integration and a companion to PowerPlay.

Colors: midnight navy #030718, cyan #00F2F1, blue #1261FF, white #FFFFFF. Keep glow only in promotional artwork; use flat color for compact in-app controls.
